# Quick Start Guide

## Prerequisites
- Android Studio (latest version)
- Android device or emulator (API 24+)
- PasteParty server running and accessible

## Setup Steps

1. **Open Project in Android Studio**
   - Open Android Studio
   - Select "Open" and navigate to the `PasteParty-Companion` folder
   - Wait for Gradle sync to complete

2. **Build the App**
   - Android Studio will automatically generate missing resources (app icons, etc.)
   - Click "Build" → "Make Project" or press Ctrl+F9
   - Resolve any dependencies if prompted

3. **Install on Device**
   - Connect your Android device via USB (enable USB debugging)
   - Or use an Android emulator
   - Click "Run" → "Run 'app'" or press Shift+F10

4. **Configure Server URL**
   - Open the app on your device
   - Enter your PasteParty server URL (e.g., `http://192.168.1.100:8081`)
   - Tap "Save"

5. **Start Sharing!**
   - Open any app (Gallery, Chrome, Notes, etc.)
   - Tap the share button
   - Select "PasteParty Companion"
   - Your content will be sent to PasteParty!

## Troubleshooting

- **App doesn't appear in share menu**: Make sure you've installed the app and granted necessary permissions
- **Connection errors**: Verify your server URL is correct and accessible from your device
- **Image sharing fails**: Check that storage permissions are granted (the app will request them automatically)

## Notes

- The app icon will be automatically generated by Android Studio
- Make sure your device and server are on the same network (or use your server's public IP)
- For HTTP (non-HTTPS) servers, the app is configured to allow cleartext traffic
